# 💗 Love QR Studio

A QR code studio made with love.

## Just use it
Open **`dist/index.html`** by double-clicking it. It is one self-contained file that works offline, on any computer. You can also send it to a phone and open it there.

## Personalize
Edit `src/config.js` to set her name, the welcome letter and the default language. Then rebuild:

```bash
npm run build
```

## Develop
```bash
npm install
npm run dev
```

## Features
- 11 content types: Link, Message, Wi-Fi, Call, SMS, WhatsApp, Email, Contact card, Location, Event, Social
- 10 color moods, dot, eye-frame and eye-center styles, square or **circle** QR codes, linear and radial gradients
- 5 frames: Plain, Polaroid, Love card, Scan me, Love letter, each with a title and caption (Bangla fonts included)
- Center badge: shapes, emoji, or her own photo (round crop with a gradient ring)
- **Live scan check**: every design is decoded on the fly, so you know it will really scan
- Export PNG (Normal / HD / Ultra HD), JPG, SVG, copy to clipboard, or share from a phone
- **Scanner**: read any QR code with the camera, a picture, drag & drop, or Ctrl+V
- English and বাংলা, dark mode, history with thumbnails, and a welcome letter in an envelope
- Shortcut: Ctrl+S downloads the PNG
